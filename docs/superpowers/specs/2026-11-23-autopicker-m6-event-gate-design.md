# M6：抓取事件门控的混合控制

用户要求继续优化“接近—退开”并检查抓取与回撤的衔接。本轮在既有研究分支执行，不改变展示场景或纯策略默认路径。

## 证据与选择

M5 的五次闭环均无 capture/collect。三个已见目标的退开命令在 attached=false 时已经由网络输出；环境没有提前切换 return。最近位置通常还伴随姿态误差。三个固定请求的诊断中，仅以相近专家状态的速度替换 qdot，预测重新接近目标。该反事实只用于诊断，不用于控制，也不足以证明唯一根因。原示范临近目标的即时动作标签没有相同的退开现象。

候选方案：补充临近抓取的动态纠偏示范；修改观测/动作表示并重训；增加明确的混合控制基线。本轮选第三项，直接检验事件衔接与可完成性。前两项留作后续纯学习方法研究。本轮不将混合控制成功算作纯扩散策略成功。

## 控制约束

新增独立 `hybrid` rollout 模式，复用冻结 M5 sample 30000 步 checkpoint。扩散策略负责粗接近。实测末端距离首次 <=0.03 m 时进入 precision，锁存一个由现有运动学求解的苹果中心/30° 姿态目标。此后不再调用网络、不重新规划 pregrasp；用现有五次平滑插值及共享限速/限加速度执行器到达并保持目标。惯性可能导致短暂距离增加，不声称距离严格单调。

只有环境记录实际 capture、attached=true 且 phase=return 后，切换 return。新轨迹以此刻已施加的执行器位置为起点，目标为现有 release_goal，hor 取此刻实测值，保持接果装置随 hor 移动的约定。旧网络动作块不再使用。实际 collect 结束回合；绝不以插值结束代替抓取或收果。附着丢失、无事件却附着、无效 IK 或跨 reset 使用控制器均失败并保留分母。

精抓和回撤是传统控制，使用真值目标和机器人运动学。这里的 IK 不是学习策略能力。门槛保持抓取 3 mm/1°、收果 25 mm、35 s 超时。新模式记录完整配置及每次 stage 转换的起点、目标、时间、持续时间和触发理由。

## 验收

先测试阶段锁存、无 capture 禁止 return、capture 当帧切换且不重用旧块、保持 hor、失败处理。顺序运行相同 train 索引 [1,2,4] 和 val [0,5]，seed=0；保留所有失败，无并行 GPU 工作。复用 M5 同权重五次纯策略基线，不声称相同跨回合随机数序列（提前停止推理会改变后续 request_id）。验收器核对 checkpoint、父数据、场景/控制源码、重置、原始事件/附着、stage 和命令轨迹；报告独立列出抓取/收果分子分母、接管次数与持续时间。未进入 3 cm 区域的失败也计入。

仅证明固定场景、单臂、真值观测、视觉吸附条件下的工程可完成性，不证明泛化、实机安全或纯扩散策略成功。
