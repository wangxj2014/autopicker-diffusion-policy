日期：2026-11-23。分支：`research/diffusion-policy`。实验从 `933aba3` 开始，运行时为未提交开发状态；数据和 checkpoint 保存各自源码散列。模型训练所用 `dataset.py`、`train.py` 与本次提交一致。后续只补强恢复采集的失败处理和实验审计，不改写已记录数据。原始 USD、演示控制器和相机没有修改。

**物理限位归一化解除示范包络限制，但本轮没有获得学习策略采摘成功。** 全量拟合 0/5、train-only 验证 0/2；另外完成 6/6 条专家恢复示范和 6/6 次转换回放。恢复数据没有混入本轮训练。完整指标、散列和逐回合结果见 [JSON 报告](2026-11-23-m2-validation.json)。

## 固定条件与唯一训练变量

两组新模型使用冻结的 `lowdim_v2`（10 回合、1,326 行、5 个目标），manifest SHA256 为 `f7d96a5015010969051af29532cbc0d2203b0cc852703fb0b5dec0a43c704fd5`。对照模型来自 M1。保留 seed=0、3,000 步、batch=64、AdamW lr=1e-4、同一 U-Net、EMA、DDIM20、clip_sample=True、观测 2 帧、预测 16 步、执行 2 步和相同软件版本。

唯一训练变量是动作仿射变换：从所选示范的 min/max 改为源场景物理关节上下限。观测变换逐项相同，train-only 仍只拟合原 train 组；all-pilot 仍明确属于全部目标参与训练的拟合诊断。训练清单、模型配置和实际 checkpoint 经过配对审计。Diffusers 的 `_use_default_values` 仅是默认参数名称集合，比较时规范化其序列化顺序，其余 scheduler 值逐项相等。

| 关节 | 物理下限 | 物理上限 | 单位 |
| --- | ---: | ---: | --- |
| roll | -1.221700 | 0.261799 | rad |
| hor | 0 | 1.200000 | m |
| ver | -0.540000 | 0 | m |
| rot | -1.910000 | 1.570000 | rad |

`--action-normalization data` 保留旧方案作为默认，`physical` 显式启用本轮方案；checkpoint 保存确切映射。原始数据集的归一化文件没有修改。物理限位上下界映射至 ±1，合法但超出训练包络的命令可被表示，观测不裁剪。

## 实际闭环结果

每回合仍需满足 3 mm / 1° 抓取门槛，再进入原 25 mm 接果范围；超时为 35 s。学习控制没有 IK 补救。

| 策略 / 范围 | M1 抓取、收果 | M2 抓取、收果 |
| --- | ---: | ---: |
| all-pilot，5 个已见目标 | 0/5、0/5 | 0/5、0/5 |
| train-only，同一留出目标重复两次 | 0/2、0/2 | 0/2、0/2 |

7 次新策略回合均执行到 35 s 超时，全部进入统计。相同目标顺序的最近末端距离如下；该距离没有包含同时满足姿态阈值的保证。

| 目标 / 模型 | M1 最近距离 (mm) | M2 最近距离 (mm) |
| --- | ---: | ---: |
| Apple_036 / all-pilot | 10.759 | 37.243 |
| Apple_035 / all-pilot | 53.766 | 169.156 |
| Apple_026 / all-pilot | 73.736 | 233.624 |
| Apple_049 / all-pilot | 87.758 | 219.016 |
| Apple_034 / all-pilot | 202.925 | 47.736 |
| Apple_036 / train-only，第 1 次 | 76.059 | 62.313 |
| Apple_036 / train-only，第 2 次 | 77.797 | 56.189 |

闭环分布偏移依然明显。以每次请求的当前观测统计，all-pilot 的 hor 速度超出拟合示范范围的次数从 **291/875 增至 544/875**；train-only 验证从 **220/350 增至 268/350**，容差均为 1e-5。扩大动作范围消除了表示限制，但本次训练没有学会稳定使用新增范围。不能仅凭部分距离变小或 loss 下降宣称改善。

all-pilot 请求往返平均 77.7 ms、P95 118.4 ms、最大 226.2 ms；train-only 验证平均 76.2 ms、P95 108.5 ms、最大 161.3 ms。全量诊断中出现超过 200 ms 重规划周期的请求。仿真仍锁步等待，每 35 s 仿真约耗时 50–55 s；这些数据不构成端到端实时性证明。没有在策略回合期间并行训练模型。

## 恢复数据与验收

仅选择原 train 的 Apple_035、Apple_026、Apple_034。每个目标取首次示范 capture 前 0.5 s 的实测全关节状态，对活动臂分别施加正负 `[3°, 25 mm, 20 mm, 5°]` 偏移；其他关节初态保留。初速度归零并执行物理稳定，随后由专家恢复接近、采摘和放果。

- 原始恢复数据：`datasets/autopicker/m2_recovery_raw_v1`，**6/6 抓取并收果**，每次保留 0.2 s 真实收果后保持记录。
- 转换导出：`datasets/autopicker/m2_recovery_lowdim_v1`，**685 行、6 回合、3 个 train 目标**，val/test 均为空。
- 导出 manifest SHA256：`b08522b9a197b6aba23b9152c05b232a888725d6c4552178817451fec7cad8be`。
- 转换动作回放：`runs/autopicker/m2_recovery_replay_v1`，**6/6 抓取并收果**，继续使用原限位、限速、限加速度执行器和采摘判定。
- 元数据记录源数据与回合散列、源行与时间、扰动、请求及稳定后的关节位置；禁止越限裁剪，失败尝试留在分母中。数据不足以通过原始回合审计时保存 `failure.json`。

这是静态初态恢复示范，不是运动中扰动、策略访问状态上的专家纠正或 DAgger；不能据此声称已经覆盖学习策略产生的大速度偏差。本轮尚未训练恢复增强模型，所以没有恢复数据提升学习成功率的证据。
