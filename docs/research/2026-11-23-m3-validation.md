# M3：恢复示范的等预算训练消融

日期：2026-11-23。分支：`research/diffusion-policy`。实验从 `e3628f2` 开始，运行时为未提交开发状态。checkpoint 和原始回合保存实际源码散列。训练完成后补强了恢复数据的稳定初态及重复轨迹校验；重新审计确认训练窗口和归一化未改变，没有改写或重新训练该 checkpoint。原始 USD、演示控制器和相机未修改。

**加入六条静态恢复示范后，本轮采摘成功率没有提高：已见目标仍为 0/3，留出目标仍为 0/2。** 两个已见目标的最近距离变小，但留出目标距离变大；所有新增试验都在原 35 s 超时门槛下失败，没有放宽成功条件。

## 实验设计

比较 M2 原 train 物理动作归一化模型与“原 train + 六条恢复示范”模型。主数据集始终为 `lowdim_v2`，保持既有目标划分和评估身份；恢复集为 `m2_recovery_lowdim_v1`，仅来自原 train 的 Apple_035、Apple_026、Apple_034，每个目标两种静态扰动。

- 主数据集 SHA256：`f7d96a5015010969051af29532cbc0d2203b0cc852703fb0b5dec0a43c704fd5`。
- 恢复数据集 SHA256：`b08522b9a197b6aba23b9152c05b232a888725d6c4552178817451fec7cad8be`。
- 基线 checkpoint SHA256：`26031d4e8625e715f38c4159187d405d2cfb906dc63e6d09bc75f2afc379b83d`。
- 增强 checkpoint SHA256：`b72e353b8c6f315402c348f4f2230fb785edb2d2bee0772c30ea5e398434800c`。

固定 seed=0、3,000 次更新、batch=64、AdamW lr=1e-4、U-Net、EMA、DDIM20、clip_sample=True、观测 2 帧/预测 16 步/执行 2 步、10 Hz 动作节点和 480 Hz 物理执行。整个 normalizer 与 M2 逐项一致，包括原 train 的观测范围及物理关节动作映射。主数据的 val/test 不进入增强训练。

原 820 个训练窗口与恢复 685 个窗口组成 1,505 个窗口，均匀抽样，恢复窗口占 **45.51%**。固定总更新数下，原数据的期望抽样量从 192,000 降至约 104,611 次，每个原窗口的期望曝光从 234.15 降至 127.57 次。因此本实验评估的是这项明确的等预算增强方案，不能将结果解释为恢复数据在任意采样权重或训练预算下的效果。

## 实际闭环结果

前两组分别用 M2、M3 在原 train 索引 `[1,2,4]`（三个不同已见目标）上执行配对测试；第三组用 M3 在 val 索引 `[0,5]`（同一留出目标两次）上执行测试。验证基线复用 M2 的两条记录，因此本轮新增 **8 次**闭环评估、复用 **2 次**。全部目标初态、场景、控制配置和随机种子一致，没有新增 test 闭环。

抓取仍要求 3 mm / 1°，收果范围仍为 25 mm，超时仍为 35 s。学习控制不调用专家 IK。各组顺序运行，不与 GPU 训练或其他 GPU 推理并行；时延只作锁步仿真测量，不代表端到端实时性。

| 范围 | M2 抓取 / 收果 | M3 抓取 / 收果 |
| --- | ---: | ---: |
| 3 个已见目标 | 0/3、0/3 | 0/3、0/3 |
| 1 个留出目标重复 2 次 | 0/2、0/2 | 0/2、0/2 |

全部 8 次新增试验都执行至 35 s，均没有 capture 事件。最近未附着末端距离如下；该位置指标不保证同时满足姿态条件。

| 目标 / 范围 | M2 最近距离 (mm) | M3 最近距离 (mm) |
| --- | ---: | ---: |
| Apple_035 / 已见 | 8.422 | 9.415 |
| Apple_026 / 已见 | 154.258 | 12.917 |
| Apple_034 / 已见 | 18.992 | 7.811 |
| Apple_036 / 验证第 1 次 | 62.313 | 97.082 |
| Apple_036 / 验证第 2 次 | 56.189 | 81.140 |

已见目标 Apple_026 和 Apple_034 更接近目标，Apple_035 略变差；验证目标两次均变差。只有一个种子和少量目标，不能据此作统计显著性或泛化结论。

以冻结的**原 train 观测范围**作为共同参考，hor 速度越界请求数在已见目标上从 388/525 降至 296/525，在验证上从 268/350 降至 212/350，容差为 1e-5。这只是相对于原归一化拟合范围的描述；恢复数据本身扩大了部分速度范围，不能把该统计直接称为超出增强训练集的比例，也不能据此认定控制已稳定。

| 范围 / 模型 | 请求往返均值 (ms) | P95 (ms) | 最大 (ms) |
| --- | ---: | ---: | ---: |
| 已见 / M2 | 94.5 | 108.6 | 125.3 |
| 已见 / M3 | 104.1 | 114.9 | 128.6 |
| 验证 / M2 | 76.2 | 108.5 | 161.3 |
| 验证 / M3 | 104.2 | 116.4 | 123.8 |

新增试验每 35 s 仿真耗时约 59–62 s。仿真等待推理时不推进时间，复用的 M2 验证计时也来自较早运行；不把这些时延差异归因为数据增强效果。

## 下一步与限制

当前只验证了固定场景、单臂、真值输入、视觉吸附、一个训练种子的等预算实验。六条恢复示范从扰动后的静态初态开始，速度归零后再稳定，未覆盖策略在实际运动中到达的全部位置/速度组合；它们不是在线专家纠正或 DAgger。

下一步应优先采集**策略实际偏离状态上的专家纠正**：仅使用 train 目标，保存接近失败时的全关节位置、速度与果实状态，在保持动态状态的前提下恢复专家控制；先验证重置和专家恢复，再与静态恢复数据做配对消融。每次失败和专家介入都要保留，评估时继续禁止 IK 补救。训练预算和混合权重若调整，应另设对照，不能将多个变化混为一项结论。

在已见目标获得可复现的闭环成功前，不扩展论文级泛化宣称。后续仍需更多独立场景/目标、多种子、视觉输入和真实接触条件验证。
